# Soundroom — Music Player UI

A responsive music-player interface built with vanilla HTML, CSS and JavaScript.

## Features
- Responsive player layout, mood filters and track search
- Play/pause, previous/next, seek, volume, shuffle, repeat and like controls
- Helpful feedback when local audio files are missing

## Add audio
The repository does not include music files. Add tracks you own or are licensed to use as `songs/1.mp3` through `songs/5.mp3` (additional tracks can be added in `script.js`). Open `index.html` in a browser or serve the folder with a static file server. Do not commit copyrighted audio without permission.
